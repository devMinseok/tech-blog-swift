# 시리즈 기능 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 시리즈 → 주제 → 편 3단계 구조를 Markdown 파일만으로 정의하고, 시리즈 목록, 시리즈, 주제 페이지와 글 페이지의 위치 표시·이전/다음 편을 정적 생성한다.

**Architecture:** 기존 모듈 경계(Model → Router → View → Builder)를 따른다. BlogCore가 `Content/Series`를 읽고 검증한 뒤, 공개 글과 묶어 화면용 `SeriesCatalog`를 만든다. BlogRouter에 라우트 3종을 추가하고, BlogViews가 렌더링하며, BlogSite가 페이지와 sitemap을 생성한다.

**Tech Stack:** Swift 6.3.3, SwiftPM, swift-html, swift-markdown, swift-url-routing, XCTest

**Spec:** `docs/superpowers/specs/2026-10-17-series-design.md`

## Global Constraints

- 잘못된 콘텐츠는 경고가 아니라 빌드 실패로 처리한다(`ContentError` throw).
- 모든 URL은 `SiteRoute` + `SiteConfiguration`/`BlogRouter`로 만든다. basePath가 `""`일 때와 `/repo`류일 때 모두 동작해야 한다.
- 슬러그 규칙은 `Slug.isValid`를 그대로 쓴다. 첫 시리즈 slug는 `teardown`이다.
- 글 front matter 필드 이름은 `series`, `topic`, `part`이고, 주제 상태 값은 `ongoing` | `completed`(기본값 `ongoing`)다.
- 시리즈 정의 파일 이름은 `_series.md`다. 위치는 `Content/Series/<series-slug>/_series.md`이고, 주제 파일은 같은 디렉터리의 다른 `.md` 파일이다.
- 화면 문구는 위치 표시가 `"<시리즈 제목> › <주제 제목> · <n>편"`, 상태가 `"연재 중"` / `"완결"`, 카드 메타가 `"<n>편 · <상태>"`, 메뉴가 `"시리즈"`다.
- 첫 화면(HomeView)과 Atom 피드 구조는 변경하지 않는다. 시리즈 글은 기존 목록, 태그, 피드에 그대로 포함된다.
- 글과 주제 콘텐츠는 만들지 않는다. 추가하는 콘텐츠는 `Content/Series/teardown/_series.md` 하나뿐이다.
- 작업 브랜치는 `feature/series`다(main에서 분기).

## Review Focus

1. 초안인 1편만 있는 주제: 운영 빌드에서 주제 카드와 페이지가 생기지 않아야 하고, 시리즈에 공개 주제가 없으면 시리즈도 숨겨야 한다. → Task 3 `testHidesTopicsAndSeriesWithoutPublishedParts`
2. 2편이 초안인 상태에서 3편을 볼 때: 이전 편은 1편이어야 하고 표시 번호는 "3편"이어야 한다. → Task 3 `testNeighborsSkipHiddenParts`
3. `Content/Series`가 아예 없는 저장소(현재 테스트 픽스처 포함): 빌드가 성공하고 시리즈 목록은 빈 상태로 나와야 한다. → Task 1 `testMissingSeriesDirectoryIsEmpty`, Task 7 기존 사이트 테스트
4. `Content/Series` 최상위에 디렉터리가 아닌 파일이 있는 경우(예: `README.md`): 무시해야 한다. → Task 1 `testIgnoresTopLevelFiles`
5. basePath가 있을 때 위치 표시 줄, 이전/다음, 주제 카드 링크에 basePath가 붙어야 한다. 빠지면 LinkValidator가 실패한다. → Task 5, 6 스냅샷 테스트(`/repo` 사용), Task 7 사이트 테스트
